### New Features

- Added a gesture to adjust playback speed
- Added pinch-to-zoom support
- Added support for higher default video resolutions
- Added an option to clear all subscriptions
- Restored support for SABR playback

### Bug Fixes

- Fixed an issue where logged-in users receive a "Content Unavailable" error and cannot watch videos
- Fixed an issue where Bluetooth hardware controls do not work
- Fixed the inability to fast-forward or rewind on TV
- Fixed an issue where Mix playlists and "Topic" channels are not correctly parsed (YouTube)
- Fixed an issue where playlists from blocked channels are not filtered
- Fixed an issue where blocked channels are still accessible via click navigation
- Fixed missing paid indicators in local playlists
- Fixed an issue where search returns no results and paid tracks show generic errors (Bandcamp)
- Fixed crashes on specific devices during certain operations

### Behavior

- Search filter persistence is now optional and disabled by default
- Fetching channel information is now optional when importing subscriptions
- Subscription update failures now prompt an error with a detailed report
- Long-pressing the "Not loaded" area now displays a list of channels that failed to update

### UI

- Subscription import and export options are now also available in Backup Settings
