## 🎯 功能概述

在 PipePipe 的播放器里新增一个 **☁️ 弹幕翻译**按钮，实现：

1. **下载视频的完整弹幕列表**。
2. **逐条（去重后）翻译**。
3. **缓存翻译结果**。
4. **按时间轴加载到弹幕流**，观看时自动显示翻译。
5. 再次进入该视频时**自动加载缓存**（无需重复下载+翻译）。

---

## 🚫 重要限制：**仅适用于"回放"，不适用于"直播"**

> **❗ 该功能的"全量下载"方式**依赖**回放（VOD / 直播回放）已经产生完整的弹幕列表**。
> - ✅ **回放 / VOD / 直播回放**：可以下载全部弹幕 → 翻译 → 按时间轴回放。
> - ❌ **正在进行的直播（Live）**：**无法使用**。直播的弹幕是"实时流"，没有"全量列表"可下载；本项目不做弹幕流式实时翻译。

**原因**：本项目采用 **"先拿全量、再整批翻译、最后加载"** 的批量思路（见下文代码逻辑），这与正在直播的弹幕流（只能实时抓取、无法回放全量）不兼容。

---

## 🧠 代码逻辑说明（批量化）

**核心思路：下载全部弹幕 → 翻译 → 缓存 → 按时间轴加载**（不是流式逐条翻译）。

以 YouTube 直播回放为例（`YouTubeReplayDanmakuFetcher`）：

1. **下载全量弹幕**
   - 从视频页提取直播回放的初始 continuation。
   - 通过 `live_chat/get_live_chat_replay` 逐页翻页（`paginate`），直到取完整个回放。
   - 每条弹幕得到：**文本**（`replayChatItemAction...message.runs[].text`）和**时间戳**（`videoOffsetTimeMsec`，视频内毫秒位置）。
   - 采用"playerOffset 随页码推进"的翻页方式，保证能拿到完整列表（而非只拿到一页/当成直播流）。

2. **去重 + 翻译**
   - 把**文本去重**（相同弹幕只翻译一次，省 token / 时间）。
   - 用所选引擎逐批翻译（每批若干条），并**缓存结果**。

3. **缓存**
   - 每条弹幕以 **`原文 + 译文`** 的形式存入 `files/danmaku/<视频hash>.json`，并维护一个索引，供"缓存管理"界面列出/删除。
   - **原文 与 译文 分开存**，因此"显示原文"开关可以随时切换（加载/下载时总是存完整 `译文\n原文`，渲染时才按开关决定是否显示原文）。

4. **按时间轴加载**
   - 翻译完成后，把完整列表交给弹幕播放器（`MovieBulletCommentsPlayer.loadDownloaded`）。
   - 播放器**边播边按当前播放位置**，取出落在 `[上一帧位置, 当前位置)` 时间窗口内的弹幕画出来——**显示的是翻译后的弹幕，且与视频时间轴对齐**。

5. **自动加载**
   - 下次进入同一个视频时，检测是否存在缓存：**有 → 直接加载缓存**（秒开，不重新下载/翻译）；**无 → 走正常加载**。

> 所以整体是：**全量下载 → 去重翻译 → 持久化缓存 → 按时间轴回放展示**。**不能用于直播**，只能用于**回放**。

## 🎬 在线字幕（外挂字幕）功能

在弹幕翻译之外，本 fork 还加了**在线字幕**：手动/跳转加载一部视频的 ASS/SRT 字幕并叠加显示，并提供一个 **"有字幕的视频"跳转列表**。

### 1. 加载在线字幕（播放器）
- 播放器里新增了**字幕按钮**（在弹幕翻译按钮旁）：
  - **第 1 次点** → 从字幕仓库在线拉取该视频字幕（`<仓库基础地址>/<视频ID>.ass`，失败再试 `.srt`），解析并叠加显示。
  - **再点** → 显示/隐藏字幕（不重复下载）；换视频自动清空。
  - **长按字幕按钮** → 循环切换字幕字号：50% → 80% → 120% → 循环（默认 80%），选择会记住，下次打开仍生效。
- **加载本地字幕**：字幕按钮旁新增 **➕ 按钮** → 打开系统文件选择器，选手机里的 `.ass` / `.srt` 文件（支持 UTF-8/带 BOM 的 UTF-16/GBK），解析后叠加到当前正在播放的视频上（与在线字幕同一套渲染；未在播视频时会提示先播放）。
- **ASS 说话人分离**：尊重 Aegisub 在 ASS 里固定的**位置**，并按**说话人自动分配不同边框颜色**；文本用捆绑的**霞鹜文楷**字体。
- **位置**：逐行保留 ASS 原始行位置与 `\pos(x,y)` 定位置（多行英文+中文会按每行宽度分别居中，不会偏左）。
- 从列表跳转进视频时，**开始播放后自动加载字幕**（不会过早加载）。

### 2. "有字幕的视频" 跳转列表
左侧抽屉"历史"下方新增 **"有字幕的视频"** 入口，打开后：
- 列出字幕仓库 `index/index.json` 里的视频：**封面 + 标题**（标题来自 index.json，可填你自己的翻译）。
- **搜索**：顶部搜索框按**标题/视频 ID**实时过滤。
- **最新在前**：按 index.json 的 `date` 字段**新→旧**排序（有 date 时）；否则按清单顺序。
- **无限滚动**：滑到底自动加载更多（每批 50 条），不会一次塞太多。
- **一键清缓存**：右上角删除图标，清空字幕缓存并重新拉取。
- 点击某项 → 跳进该视频并在播放后自动加载字幕。

### 3. 字幕仓库（怎么添加自己的字幕）
- 结构（公开示例：`github.com/CCCMNSB/subtitles`）：
  ```
  subtitles/<视频ID>.ass|.srt   ← 字幕文件（以视频 ID 命名）
  index/index.json              ← 清单 [{id, title, date}]，顺序即显示顺序
  generate-index.ps1            ← 扫描生成 index.json（标题用 oEmbed，保留已有 title）
  ```
- 每新增一部视频的字幕：把 `<视频ID>.ass` 放进 `subtitles/`，并在 `index.json` 加一条 `{id, title, date}`。`title` 可写你的翻译，App 直接显示/搜索，**不走任何 API**。
- 跳转列表**只读 `index.json`**，所以 `index.json` 里没有的视频不会出现在列表里。

### 4. 设置（设置 → 高级 → 弹幕设置 → 在线字幕）
- **启用在线字幕**：开关（默认开）。
- **字幕仓库基础地址**：默认 `https://raw.githubusercontent.com/CCCMNSB/subtitles/main/subtitles`。列表从其 `index/` 读 `index.json`；**换仓库即可切换列表与字幕来源**（回到列表页自动刷新）。
- **字幕字体**：霞鹜文楷 / 衬线 / 无衬线 / 等宽。
- **字幕缓存**：显示已缓存条数/大小，可**逐条删除 / 一键清空**（清空后重新拉取）。

### 5. 缓存
- 列表清单 `index.json`：缓存 **10 分钟 TTL**，且**按来源仓库存储**（换仓库自动失效、重拉）。
- 已加载字幕：本地缓存（**cache-first**），再次播放秒开。
- 缓存管理入口见上面设置里的"字幕缓存"。

### 6. 说明
- 在线字幕是**手动/跳转触发**，不自动扫描所有视频；是**外挂字幕**（不改视频本体，与"硬烧录"不同）。
- 字幕仓库公开、多人用没问题：走 **raw CDN / 图片 CDN**，不依赖会限流的 `api.github.com`。

### 在线弹幕 (ASS) 详细说明

- **来源**：字幕仓库 `danmaku/<视频ID>.ass`（公开仓库，raw CDN 加载）。
- **渲染**：ASS `\move` 指令驱动弹幕从右向左滚动（canvas 自动裁剪，弹幕从边缘"推进"画面）。
- **字号**：独立于字幕字号，可在设置里调整（默认 80%）。
- **原文显示**：可开关"在译文下方显示原文"（ASS 里 `translated\Noriginal` 格式）。
- **刷新频率 (FPS)**：可选 30 / 60 / 90 / 120 fps（默认 60）。越高越流畅，但耗电更多。
- **缓存**：弹幕文件缓存在 App 内部存储（`files/subtitles/danmaku/`），**卸载 App 时自动清除**（`ACTION_DELETE` 广播接收器）。
- **仅回放**：与弹幕翻译一样，**不支持直播**（需要 ASS 文件已存在于仓库）。

### 设置（设置 → 高级 → 弹幕设置）

| 设置项 | 说明 |
|---|---|
| **弹幕字号** | 在线弹幕（ASS）字号缩放，独立于字幕字号。80% 为默认。 |
| **弹幕刷新频率** | 弹幕滚动动画的帧率：30 / 60 / 90 / 120 fps。越高越流畅，但耗电更多。60 为默认。 |
| **在译文下方显示原文** | 开启后，原文以更小字号显示在译文下方；关闭则只显示译文。 |
| **翻译引擎** | LLM（推荐）/ ML Kit。 |
| **弹幕缓存** | 管理已缓存的翻译弹幕（逐条删除 / 一键清空）。 |

## ⚙️ 翻译引擎（可切换：设置 → 高级 → 弹幕设置 → 翻译引擎）

| 引擎 | 说明 | 需联网 | 需 Google 服务 | 推荐 |
|---|---|---|---|---|
| **LLM**（**推荐**） | OpenAI 兼容大模型（DeepSeek 云端 / 本地 Ollama/llama.cpp）| 是（本地走局域网） | 否 | ⭐ **强烈推荐** |
| **ML Kit** | Google 端上离线模型 | 否 | ✅ 需要 | ⚠️ 不推荐 |

> **🟢 推荐只使用 LLM。** 理由：LLM 翻译质量最好，且**国内手机无需 Google 服务框架**也能用（联网即可）。
> **🔴 ML Kit 不推荐**：它需要 **Google Play 服务** 才能下载离线模型，国内多数手机没有 → 会失败；且质量一般。仅在你**完全不想联网 / 有 Google 服务**时才作离线兜底。

**LLM 推荐搭配（DeepSeek）**，设置里"LLM source"一键切换：
- **Cloud (online)**：填 OpenAI 兼容地址 + key + 模型（DeepSeek：`https://api.deepseek.com` + `deepseek-chat`）。
- **Local (LAN)**：连接你自己电脑上跑的本地大模型（Ollama / llama.cpp，暴露 OpenAI 兼容 `/v1` 接口），手机通过局域网调用（免 key、离线）。

## 🎛️ 其它功能

- **进度提示**：下载/翻译时的 toast 进度，间隔可调（`弹幕设置 → 下载进度提示间隔`，默认每 100 条）。
- **显示原文开关**：`弹幕设置 → 显示原文`。开 = 译文+原文两行；关 = 只显示译文。随时切换，始终生效。
- **缓存管理**：`弹幕设置 → 弹幕缓存 → 管理`，列出已缓存视频（条数/大小），可逐条删除 / 一键清空。
- **顶部弹幕裁剪修复**：两行文本不再被顶出可视区。
